# Agent instructions

Read and follow CONTRIBUTING.md. The people on this project only talk to their agents. You handle the whole workflow from planning a request to merge, and you report back using the Plan, Done, and Blocked formats in CONTRIBUTING.md. Read the docs in docs/agents/ at the steps CONTRIBUTING.md points to: verification before opening a PR, review triage when Codex responds, and design red flags before changing a shared contract. SSH access and rules for the shared GX10 machine are in docs/gx10.md. The system design and build plan are in docs/ARCHITECTURE.md; the skill file format is in docs/skills.md.

New teammates: start with [docs/agents/teammate-handoff.md](docs/agents/teammate-handoff.md) for shared-machine access and the setup already in place. Before taking a build task, read docs/lanes/README.md and your lane's brief; only edit the paths your lane owns.
